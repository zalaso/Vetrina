# Screenshots

Three images belong here. Until they do, the Screenshots section in `README.md`
and `README.it.md` is commented out, so the front page does not show broken
image icons.

| File | What it should show |
| --- | --- |
| `home.png` | The shop window: the home page, top of the fold |
| `item.png` | A single item's page — photo gallery, description, contact box |
| `telegram.png` | The Telegram chat publishing a piece: photo, summary, ✅ / ✏️ buttons |

**Capturing them**

- The two site shots: a desktop browser at **1440px wide**, PNG. Either your own
  instance or the built-in example shop (`cd site && npm run dev` with no `.env`,
  which gives the fictional "Bottega del Ponte" and a sample catalogue).
- The Telegram one: a phone screenshot, cropped to the conversation. Check it
  carries no real customer names or phone numbers before committing it.

**Switching them on**

Once the three files are here, in both `README.md` and `README.it.md` replace the
italic "not in the repository yet" line with the table that sits just below it,
inside the HTML comment.
