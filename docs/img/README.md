# Screenshots

The three images shown in `README.md` and `README.it.md`.

| File | What it shows |
| --- | --- |
| `home.png` | The shop window: pieces on the home page |
| `item.png` | A single item — gallery, price, the description the AI wrote, the characteristics table |
| `telegram.png` | The whole publishing flow in one shot: photo and caption in, summary out, ✅ / ✏️ buttons, confirmation |

**Replacing them**

Keep the same three filenames and both READMEs pick the new ones up with no edit.
Capture the two site shots from a desktop browser around **1400px wide**, PNG; the
current ones are roughly 1365×630. `telegram.png` is a phone or desktop client
screenshot cropped to the conversation.

Before committing a new one, check it carries no customer names, phone numbers or
addresses: this repository is public, and text removed from the code is not removed
from a picture of it.
